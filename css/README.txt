💡 Gdzie możesz zmieniać tła:

Cała strona → body { background-color: ... } w base.css

Sidebar → .sidebar { background-color: ... } w sidebar.css

Główny nagłówek → .main-header { background-color: ... } w main.css

Kontener wykresu → .chart-container { background-color: ... } w main.css

Panel statystyk → .stats-container { background-color: ... } w stats.css

Poszczególne statystyki → .stat-item { background-color: ... } w stats.css

Stopka → .page-footer { background-color: ... } w stats.css
